# Demo background media

Sample videos and posters used by the demo seed (`flask seed-demo`). They are stand-ins
from the design draft: replace them in the admin panel under Site appearance, tab
Backgrounds. File names match the background keys (`home-hero.mp4`, `home-hero.webp`, ...).

All videos are H.264 without audio, under 0.5 MB each, with a WebP poster. The sample videos
carry a generator watermark in a corner; real restaurant footage replaces them before launch.
